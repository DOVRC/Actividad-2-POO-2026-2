## Descripción

En este repositorio se encuentran los cinco ejercicios correspondientes a la Actividad 2 de Programación Orientada a Objetos, desarrollados en Java a partir del libro *Ejercicios de programación orientada a objetos con Java y UML*, de Leonardo Bermón Angarita.

Para cada ejercicio se incluye el código fuente, los diagramas UML de clases y objetos, y un README con una breve explicación e instrucciones para ejecutar el programa.

También se realizaron los ejercicios propuestos que aparecen al final de cada sección del libro.

## Ejercicios

| Ejercicio | Tema |
| --- | --- |
| [2.1](ejercicio_2_1/) | Definición de clases — Persona |
| [2.2](ejercicio_2_2/) | Atributos y tipos primitivos — Planeta |
| [2.3](ejercicio_2_3/) | Estado de un objeto — Automóvil |
| [2.4](ejercicio_2_4/) | Métodos con y sin retorno — Figuras geométricas |
| [2.5](ejercicio_2_5/) | Métodos con parámetros — Cuenta bancaria |

Los ejercicios están organizados en carpetas independientes, de manera que cada uno se puede consultar, compilar y ejecutar por separado.
